# SEMSEG — Sistemas de Gestão

Repositório de desenvolvimento dos sistemas internos da Secretaria Municipal de Segurança.

## Aplicação em desenvolvimento

- `apps/compdec-gestao/` — Sistema de Gestão Integrada da COMPDEC para estoque, NUPDECs, equipes, voluntários, treinamentos, reuniões, avisos, documentos, cautelas, solicitações de materiais, auditoria e prontidão operacional.

> O repositório contém somente código e dados fictícios de demonstração. Dados reais e documentos operacionais devem permanecer em serviços autenticados, como Firebase Authentication, Firestore e Storage.
