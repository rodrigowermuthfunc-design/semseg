# Checklist LGPD para entrada em produção

- [ ] Controlador, operador(es) e encarregado definidos pelo Município.
- [ ] Finalidades e bases legais documentadas para cada grupo de dados.
- [ ] Apenas dados necessários são coletados.
- [ ] Dados sensíveis não são coletados sem necessidade e base legal específica.
- [ ] Prazo de retenção e procedimento de descarte definidos.
- [ ] Processo para acesso, correção e demais direitos do titular definido.
- [ ] Perfis de acesso aprovados formalmente e revisados periodicamente.
- [ ] MFA habilitado para perfis administrativos.
- [ ] App Check em enforcement para Auth, Firestore, Storage e Functions.
- [ ] Firestore e Storage Rules testadas em emuladores.
- [ ] IAM revisado com privilégio mínimo.
- [ ] Backups e restauração testados.
- [ ] Plano de resposta a incidentes e comunicação definido.
- [ ] Logs protegidos e sem dados pessoais desnecessários.
- [ ] Teste de invasão realizado antes da carga de dados reais.
- [ ] Termo de uso/política de privacidade institucional publicados quando aplicável.
